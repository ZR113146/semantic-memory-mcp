# ADR: layer field defaults to "adr" for decision and constraint memories

## Summary

ADR identity: decision-class memories default to layer="adr" instead of "episodic" for differentiated retrieval, ranking, and decay tuning

## Content

**决策**：kind=decision 和 kind=constraint 的记忆写入时，若调用方未显式传 layer 参数，默认设 layer="adr"（而非 "episodic"）。

**背景**：截至 2026-07-07，97% 的决策记忆（66/68 条）以 layer="episodic" 存储。mcp.c:5026 的硬编码默认 `item.layer = layer ? layer : "episodic"` 无条件适用所有 kind。这导致无法按 layer 过滤、排级或设定差异化 decay 策略。schema 中 `layer` 字段的 `"adr"` 值虽然定义了，但从未作为默认使用。

**否决的替代**：
- 改 schema DEFAULT 值（ALTER TABLE）：需要迁移 87 条已有行，风险大且对未传 layer 的调用方可能静默破坏
- 独立 ADR 表：分叉写入路径，测试面翻倍，无实质收益——memory_item 已有所有需要的列

**锚点**：mcp.c ~L5026（P0-a 修改）、store.c ~L3769（配合 P2 decay 调优）、2026-07-07 commit
