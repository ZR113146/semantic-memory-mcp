# 新增 adr_list MCP tool：人类可浏览、可过滤的 ADR 索引（架构决策的 MEMORY.md 等价物）

## Summary

新增 adr_list MCP tool：人类可浏览、可过滤的 ADR 索引（架构决策的 MEMORY.md 等价物）

## Content

[Decision] 新增 adr_list MCP tool 作为 ADR 的人类可浏览索引(MEMORY.md 等价物)。返回结构化 JSON 列表，支持 project/kind/status/entity_key 过滤和 limit。API：adr_list {project, kind?, status?, entity_key?, limit?} → {project, total, items:[17 列：id/kind/layer/title/summary/entity_key/status/importance/confidence/reusability/specificity/hit_count/decay/version/supersedes/created_at/updated_at]}。

[Context] ADR 以 memory_item 行存储，唯一检索是 memories_retrieve 的 FTS/向量语义查询——没有 MEMORY.md 式的"目录"视图。用户无法不靠语义碰运气就回答"这项目有哪些活的决策"。adr_list 提供零查询词的轮廓概览。存储层 SQL：SELECT 17 列 + 参数化过滤(scope_project + 可选 kind/status/entity_key) + ORDER BY 复合得分 DESC + LIMIT。

[Rejected alternatives] (a) 纯前端 Graph UI——需 HTTP server+浏览器，不适 MCP-only 会话。(b) 扩展 memories_retrieve 加 layer 过滤——改 cbm_memory_query_t 波及 10+ 调用方，且语义查询与目录查询是正交需求。
