# adr_list: removed from ADMIN_TOOLS, heap_strndup→heap_strdup fix

## Summary

adr_list removed from ADMIN_TOOLS for MCP client visibility; heap_strndup → heap_strdup fix in store.c

## Content

The `adr_list` tool was initially added to ADMIN_TOOLS[] (which hides it from the default tools/list). After discussion, it was removed so the MCP client (Claude Code) can see and use it. The tool is a read-only query with no side effects, making it safe to expose.

Additionally, the `heap_strndup` function used in store.c's adr_list implementation does not exist in store.c (only heap_strdup exists). Fixed by using heap_strdup instead — the yyjson_mut_write output is already NUL-terminated, so the extra length parameter was unnecessary.
