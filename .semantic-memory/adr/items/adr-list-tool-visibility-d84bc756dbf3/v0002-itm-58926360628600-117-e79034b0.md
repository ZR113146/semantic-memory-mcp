[Decision] adr_list 作为只读、无副作用的查询工具，应对 MCP 客户端(Claude Code)可见，不藏在 admin-gating 后。同时修其 store 实现里误用的 heap_strndup(store.c 无此函数)→改 heap_strdup(yyjson_mut_write 输出已 NUL 结尾，多余长度参数不需要)。
