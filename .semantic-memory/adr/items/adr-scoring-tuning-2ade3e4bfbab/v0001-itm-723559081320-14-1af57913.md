# ADR: gentler decay recovery (-0.07) and higher baseline reusability (0.7) for unanchored ADRs

## Summary

ADR scoring tuning: gentler decay recovery (-0.07 vs -0.10) and higher baseline reusability (0.7) for unanchored ADRs

## Content

**决策**：ADR（kind=decision/constraint）的 recall decay 恢复系数从 -0.10 降至 -0.07；无 about_code 锚点的 ADR 默认 reusability 从 0.5 升至 0.7。

**背景**：ADR 编码的是"为什么"知识，半衰期天然长于一般 episodic 条目。每次 recall 应恢复较少累积 decay。若 ADR 无 about_code 锚点（纯 memory 项目或未索引代码），graph signal 无法参与 blend，reusability 停留在默认 0.5——低值 ADR 在 structured 排序中会被挤出 top-K。

**落地**：
- P2（decay）：cbm_store_memory_mark_hits 双语句策略——先用 kind IN ('decision','constraint') 的 ADR 语句（decay-0.07），匹配 0 行则回退通用语句（decay-0.10）
- P4（reusability）：handle_events 在 about_code_n==0 且 reusability≈0.5 时，额外 UPDATE memory_item SET reusability=0.7

**否决的替代**：
- 全局改 decay-0.10：会让非 ADR 条目恢复过多 decay，降低 decay 机制整体的信噪比
- 不提升 reusability：无锚点 ADR 在排序中垫底，35% never-recalled 率会更高

**锚点**：store.c ~L3762-3810（P2）、mcp.c ~L5248-5265（P4）、2026-07-07 commit
