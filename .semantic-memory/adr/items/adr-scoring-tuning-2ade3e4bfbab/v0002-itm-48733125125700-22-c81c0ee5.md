# ADR 打分调优：decision/constraint 更缓的 decay 恢复(-0.07) + 无锚 ADR 更高 reusability 基线(0.7)

## Summary

ADR 打分调优：decision/constraint 更缓的 decay 恢复(-0.07) + 无锚 ADR 更高 reusability 基线(0.7)

## Content

[Decision] ADR(kind=decision/constraint)的 recall decay 恢复系数从 -0.10 降至 -0.07；无 about_code 锚点的 ADR 默认 reusability 从 0.5 升至 0.7。

[Context] ADR 编码的是"为什么"知识，半衰期天然长于一般 episodic 条目，每次 recall 应恢复较少累积 decay。若 ADR 无 about_code 锚点(纯 memory 项目或未索引代码)，graph signal 无法参与 blend，reusability 停留在默认 0.5——低值 ADR 在 structured 排序中会被挤出 top-K。

[Rejected alternatives] (a) 全局改 decay-0.10：会让非 ADR 条目恢复过多 decay，降低 decay 机制整体信噪比。(b) 不提升 reusability：无锚点 ADR 在排序中垫底，never-recalled 率更高。

[Anchors] 提交 8d742b7(feat(adr): ADR memory system optimization，2026-07-07)确立本调优。(decay -0.07) recall decay 恢复对 decision/constraint 用 -0.07、其余回退 -0.10，位于 cbm_store_memory_mark_hits(src/memory/memory_store.c，原 store.c 经 38f8d25 抽离)。(reuse 0.7 下限) 2026-07-08 收拢(提交 446c8cf)后，已从 handle_events 的 P4 内联块统一为 memory_kind_reuse_prior 的 kind 先验表(decision/constraint→0.7)、由 cbm_memory_score_item 应用；见 [[memory-scoring]]。
