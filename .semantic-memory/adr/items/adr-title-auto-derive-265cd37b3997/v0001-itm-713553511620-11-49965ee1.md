# ADR: auto-derive title from summary first sentence for decision-class memories

## Summary

ADR title auto-derivation: decision-class memories without explicit title derive one from the first sentence of summary, saving recall tokens

## Content

**决策**：kind=decision/constraint 写入时若未传 title，从 summary 首句自动派生 title（截取到第一个换行符，去除尾部标点）。存 heap_strdup 分配的内存，在 handle_events 的 free 路径中释放。

**背景**：截至 2026-07-07，75% 的决策条目 title 为 NULL 或 "memory.event"（系统旧默认）。recall hook 展示时 fallback 到 summary，每轮多消耗 ~40 tokens/条。summary 总是携带 query-like 的结论，提取首句作为 title 是最经济的 token 节省。

**否决的替代**：
- 留 NULL：让 recall hook 的 summary fallback 工作——但浪费 tokens，且 adr_list 展示中 title=NULL 体验差
- 要求调用方必须传 title：破坏向后兼容，纯 memory 项目无法从旧代码自然迁移

**锚点**：mcp.c ~L5119（P0-b 修改）、2026-07-07 commit
