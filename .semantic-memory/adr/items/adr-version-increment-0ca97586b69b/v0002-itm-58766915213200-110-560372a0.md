# ADR version increment: 传 supersedes 时新条目 version = 旧 version + 1，使 supersede 链自然升序

## Summary

ADR version increment: 传 supersedes 时新条目 version = 旧 version + 1，使 supersede 链自然升序

## Content

[Decision] supersedes 非空触发写入时，查被取代条目的 version，新条目 version = old_version + 1；旧条目未找到(已删/异 scope)则 version 保持默认 1。实现：handle_events 先设 item.version=1，再 SELECT version FROM memory_item WHERE id=?1 AND deleted_at IS NULL 取 +1。查询在同事务内、在 append_candidate INSERT 之前，故旧条目 version 仍存活。

[Context] 截至 2026-07-07 所有决策 version 恒为 1——supersede 链上 2-3 条全 version=1，字段上无法区分演进顺序。git 交叉核对：本项目 4 条链、zhiwei-kb 9 条链，均无版本递增。

[Rejected alternatives] (a) 用 status 转换模拟版本(active→archived→active)——不可靠，且不能表达"同一条目三版"。(b) 在 store 层递增——需改 cbm_store_memory_append_candidate 签名、破坏 API。
