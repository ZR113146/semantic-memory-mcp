# memory.event

## Summary

为什么不再用余弦相似度自动判定记忆之间的矛盾关系

## Content

【决策】移除 consolidation 里"同 explicit entity_key + cosine<0.90 → 自动建双向 contradicts 边"的规则。矛盾关系必须来自强证据(显式声明),不能靠余弦启发猜。保留 cosine>=0.90 的近义 merge。
【背景】contradicts 是高杀伤关系——memory_resolve_conflicts 会把矛盾组里除 winner 外全部从召回隐藏。真实 nomic embedding 按 topic 聚类,两条表述不同但语义一致的记忆余弦低于 0.90,被误判为矛盾(代码注释自己都承认这假设不成立)。实例:zhiwei 项目两条一致决策("保留 PPR"/"不用 HDC 替换 PPR")被误判,一条被抹除,召回 9→8。
【否决的替代】保留规则但换判据——没有可靠的自动语义矛盾判据(注释已证),换什么都是猜。只能退回"需显式证据"。
【落地锚点】cbm_store_memory_consolidate 移除自动 contradicts 块,保留 merge;提交 000d65e。同步更新了断言旧规则的测试。
