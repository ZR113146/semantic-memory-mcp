# 为什么移除按余弦相似度自动判定记忆矛盾(contradicts)的规则，改为矛盾关系只认显式证据

## Summary

为什么移除按余弦相似度自动判定记忆矛盾(contradicts)的规则，改为矛盾关系只认显式证据

## Content

[Decision] 移除 consolidation 中"同 explicit entity_key 且 cosine<0.90 → 自动建双向 contradicts 边"的规则；记忆间的矛盾关系只能来自显式强证据，不再靠余弦启发式猜测。保留 cosine≥0.90 的近义 merge 不变。

[Context] contradicts 是高杀伤关系：memory_resolve_conflicts 会把一个矛盾组里除 winner 外的条目全部从召回中隐藏。真实 nomic 静态嵌入按 topic 聚类，两条表述不同但语义一致的记忆余弦常低于 0.90，会被误判为矛盾（该阈值假设在代码注释里原本就自认不成立）。实例：zhiwei-kb 两条一致决策（"保留 PPR"/"不用 HDC 替换 PPR"）被误判，一条被抹除，召回从 9 掉到 8。

[Rejected alternatives] 保留自动规则但更换判据——没有可靠的自动语义矛盾判据（注释已自证），换任何余弦阈值都仍是猜；只能退回到"需显式证据"。
