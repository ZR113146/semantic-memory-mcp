# D4：衰减公式为什么要加入 importance 因子（高 importance 记忆衰减更慢）

## Summary

D4：衰减公式为什么要加入 importance 因子（高 importance 记忆衰减更慢）

## Content

[Decision] D4 修复：衰减公式增加 importance 因子，高 importance 记忆衰减更慢——next_decay 末尾乘以 (1.0-importance)。

[Context] 2026-07-05 修复。原 next_decay 只用 confidence×reusability，忽略 importance；importance 在排序层生效但在衰减层不生效，存在语义缺口。改三处：SQL SELECT 增加 importance 列、读取该列、公式末尾乘 (1.0-importance)。主测试套件 5521 passed / 3 skipped，无回归。

[Rejected alternatives] 不改——排序层已用 importance，但衰减层缺口仍在，真 ADR 与废笔记同速衰减；修一行即闭合，无理由不修。

[Anchors] 提交 621f9c9(fix(memory): include importance in decay formula，2026-07-05，当时改 src/store/store.c)。经 38f8d25 抽离后，衰减公式现位于 cbm_store_memory_decay(src/memory/memory_store.c)：old_decay + (age_days/30.0)·(1.0-confidence)·(1.0-reusability)·(1.0-importance)。注：本条 supersede 更早的 itm-960505336751-33，链保留。排序层公式已于 446c8cf 收拢进 cbm_memory_score_item，但本条是衰减层修复，不受影响；见 [[memory-scoring]]。
